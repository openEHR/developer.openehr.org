# openEHR Developer Guide

The openEHR Developer Guide is the developer-facing documentation site for openEHR. It starts with a practical guide to the openEHR tooling landscape; implementation and conformance guidance will follow.

The published site is at [developer.openehr.org](https://developer.openehr.org/).

## Local Preview

```sh
python3 -m venv .venv
.venv/bin/pip install -r requirements.txt
.venv/bin/zensical serve
```

## Contributing

Please open an issue or pull request with corrections and additions. Tooling changes frequently, so links to current primary sources are especially useful.
