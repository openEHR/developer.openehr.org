# Deprecated or Obsolete Tools

The following tools are still findable and downloadable but should not be used for new work.

| Tool | Reason |
| --- | --- |
| Archetype Editor (.exe, Ocean Informatics) | Windows-only, ADL 1.4 only, and superseded by Archetype Designer. |
| Template Designer (.exe, Ocean Informatics) | Windows-only, produces `.oet` files only, and is superseded by Archetype Designer. |
| Ocean Template Designer | An earlier name for Template Designer. |
| EHRscape (Marand) | An older Marand cloud platform and API with its own EHRscape API format, replaced by the standard openEHR REST API. |
| Old hosted Archetype Designer (ehrscape.marand.si) | The original Marand-hosted instance of the pre-Angular 2 Archetype Designer, superseded by [tools.openehr.org/designer](https://tools.openehr.org/designer/). |
| Archetype Finder (2005) | The first incarnation of what became CKM. |
