# Deprecated or Obsolete Tools

The following tools are still findable and downloadable but should not be used for new work.

| Tool | Owner or author | Availability | Reason |
| --- | --- | --- | --- |
| Archetype Editor | [Ocean Health Systems](https://oceanhealthsystems.com/about/) | [Installer](http://downloads.oceaninformatics.com/downloads/ArchetypeEditor/ArchetypeEditorSetup_2.8.972.1.exe) | Windows-only, ADL 1.4 only, and superseded by Archetype Designer. |
| Template Designer | [Ocean Health Systems](https://oceanhealthsystems.com/about/) | [Installer](https://downloads.oceaninformatics.com/downloads/TemplateDesigner/Internal/TemplateDesignerSetup_3.1.230.0.exe) | Produces `.oet` templates; use Archetype Designer for new work. |
| Ocean Template Designer | [Ocean Health Systems](https://oceanhealthsystems.com/about/) | [Template Designer download](https://downloads.oceaninformatics.com/downloads/TemplateDesigner/) | An earlier name for Template Designer. |
| EHRscape | [Better](https://www.better.care/about-us/) | No current public endpoint; see [deprecation discussion](https://discourse.openehr.org/t/ehrscape-api/4286) | An older Marand cloud platform and API, replaced by the standard openEHR REST API. |
| Old hosted Archetype Designer | [Better](https://www.better.care/about-us/) | [Current hosted successor](https://tools.openehr.org/designer/) | Historical `ehrscape.marand.si` host, superseded by the current hosted Designer. |
| Archetype Finder | [Sebastian Garde](https://github.com/sebastian-garde) for [Ocean Health Systems](https://oceanhealthsystems.com/about/) | [CKM successor](https://ckm.openehr.org/ckm/) | An early predecessor of CKM with no current availability. |
