# Where to Get Help

- **[openEHR Discourse forum](https://discourse.openehr.org/):** The main community hub for questions, announcements, and discussion.
- **[openEHR specifications](https://specifications.openehr.org/):** Normative specifications for ADL, AOM, RM, REST API, and AQL.
- **[openEHR CKM](https://ckm.openehr.org/ckm/):** Browse archetypes and templates.
- **[EHRbase documentation](https://docs.ehrbase.org/):** EHRbase documentation.
- **[EHRbase sandbox](https://sandkiste.ehrbase.org/):** A free sandbox requiring no installation.
- **[freshEHR GitHub (openehr_tool_docs)](https://github.com/freshehr/openehr_tool_docs):** Training setup guides. Some content is older and references legacy tools.

This guide was compiled in March 2026 from the openEHR Foundation's modelling tools and platform pages, plus community Discourse material. Given the pace of change, some details may have shifted. The openEHR Discourse forum is the best place to verify the current status of a specific tool.
